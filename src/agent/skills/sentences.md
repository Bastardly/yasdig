This model reads plain sentences, like a description written for a person, not tags. One subject alone can be one paragraph: "A close-up photograph of a red fox wearing a red knitted hat, standing in a snowy pine forest at dawn. Soft light from the left, shallow depth of field." More than one subject: elements first, then the scene, as above.
- Say what each thing looks like and where it is. Name colours, materials and positions.
- Lettering goes in quotes: a sign that says "OPEN".
- Weights like (word:1.2) do nothing useful here; say it in words instead.
- Specific prompts work better than short ones.
