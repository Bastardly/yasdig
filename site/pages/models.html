Any file, recognised by what's inside

.safetensors, .gguf or .ckpt: YASDIG reads every file to find out what it is, so names and folders don't matter. Model files are read, never run — there is no Python inside. Installed lists every file you have with the families it serves, and a note on any of them behind its blue i.

Convert

Shrink a model to GGUF — q8, q4 and others — so it fits your card. fp8 files run at twice their size on AMD cards; Convert turns one into a GGUF that runs at its real size.
