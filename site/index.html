Before you download

YASDIG is free and open source — every line of it is public on GitHub. It isn't signed with a paid Microsoft certificate yet, so Windows doesn't know it and will warn you twice:

  1. While downloading, Edge may say the file isn't commonly downloaded. Choose ⋯ → Keep, then Keep anyway.
  2. The first time you start it, Windows shows Windows protected your PC. Choose More info → Run anyway.

After that it starts like any other program. Extract the zip first (right-click → Extract All) and start yasdig.exe from the folder.

Getting started

  1. Download the file for your system, above.
  2. Extract it — on Windows, right-click the zip → Extract All. You get a yasdig folder: keep it, everything the app makes goes in there.
  3. Start yasdig in that folder. Your browser opens on the app.
  4. Open Get models, download a model, then press Generate.

You need a graphics card with a current driver (AMD, NVIDIA or Intel). How much memory depends on the model; the app says per model.

On Windows, the first start may show Windows protected your PC: choose More info → Run anyway. YASDIG is open source but not yet signed with a Microsoft certificate.
