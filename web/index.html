rustimage

Vulkan · stable-diffusion.cpp + native FSR upscale — no Python.

Turbo/LCM models: try steps 1–4, CFG 1. Standard SDXL: steps ~20, CFG ~5.

Refine and hi-res are img2img passes over the image you already have, run from the buttons above the result. Steps is how many denoising steps actually run — more steps resolve more detail, which is what cures a soft upscale. Strength is how far the pass may move from the source: 0.3 touches it up, 0.7 reinterprets it. 0 steps disables a pass and hides its button.
