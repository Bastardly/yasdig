What this is for

A file's type on disk is not what it costs to run. When the backend can't multiply the stored type — every Vulkan device today reports no fp8 — sd.cpp casts each layer's weights at run time instead, so an fp8 checkpoint executes as if it were BF16 and needs about twice its own size. Converting to a type the backend multiplies natively is smaller and faster.

The result is written beside its source, so it is discovered on the next start with no config edit. Nothing is deleted — the original stays where it is.
