What this is for

A file's type on disk is not what it costs to run. When the backend can't multiply the stored type — every Vulkan device today reports no fp8 — sd.cpp casts each layer's weights at run time instead, so an fp8 checkpoint executes as if it were BF16 and needs about twice its own size. Converting to a type the backend multiplies natively is smaller and faster.

The result is written beside its source, so it is discovered on the next start with no config edit. Nothing is deleted — the original stays where it is.

Get models

One recommended set per model family: the model and every file it needs beside it, each going to the right folder. A file you already have — under any name — is not downloaded again.

Check the licence before you use what you make. Every model has its own: some allow commercial use, some are for non-commercial or research use only, some ask you to accept terms. Each card links the pages its files come from, and a quantized copy (GGUF) is under the licence of the model it was made from. yasdig only fetches the files; the terms are between you and the people who made them.

Downloads keep going while you generate. Cancel keeps what has arrived, so Resume carries on from there.
