Vulkan · stable-diffusion.cpp + native FSR upscale — no Python.

Turbo/LCM models: try steps 1–4, CFG 1. Standard SDXL: steps ~20, CFG ~5.

Refine and hi-res are both img2img passes over the image you already have, run from the buttons above the result. Hi-res enlarges first, then diffuses — that's what invents detail the upscale can't. Refine diffuses in place at whatever size the image currently is, so it's the finishing pass: run it after a hi-res, and run it more than once if it helps. Strength is how far the pass may move from the source: 0.3 touches it up, 0.7 reinterprets it. Steps is a floor, not an exact count — strength decides how far up the noise schedule a pass starts, and starting higher needs proportionally more steps to resolve, so the number above is raised to match. Too few steps for the strength doesn't reinterpret less, it just leaves noise behind, which is what reads as grit. 0 steps disables a pass and hides its button.
