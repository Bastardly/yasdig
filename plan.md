# Feature - Favorite outputs
Currently, we can't favorite outputs, so that they are saved in the user/favorite_outputs

The work folder is more like a temporary folder, and even the outputs folder can become quite messy. Therefore it would be nice to be able to save outputs to favorites. Note this might impact image selection in image to image and video. (Just ignore video for now)

In this, we could also use a delete all button for outputs.

# Feature 2 - Close server button
Noticed this when working with the executeable. Here we can't see the console if running it from a file manager. Therefore it would be nice to have a red "Close server" button in the "tabs" row.
So when clicking that button, the user gets a confirm dialog, when confirmed, the server is shut down, and the given port is released.

# Feature 3 - Shut down settings.
This is a combination of feature 1 and 2, since the work folder can grow. Therefore it would be nice to have two setting in the settings tab:
1) Clear work items on shutdown
2) Clear outputs on shutdown
3) Clear videos on shutdown

All default false.

This should only be run when clicking the close server buitton. 

Ofcourse, the settings should do what they say. Clear /work/workitems, output etc..
