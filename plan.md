# Next steps


# 1 Feature: Batch creating
To be able to create multiple work items at a time, by setting a count.
No need for a map cap, min is 1.
Should be in card settings.

if batch value is more than one, the Generate button's text should change to "Generate X" where is is the batch amount.

# 2 Feature: Auto run
Runs workitem generation on loop until stopped. 
If activated, e.g. by a checkbox, the Generate button should say "Start loop generation"
Once started, a stop button should appear. It should not be disabled.
Clicking it will stop the loop after the current generation. Meanwhile, the stop button is disabled.
Once the loop is stopped, the stop button disappear

# 3 Feature: Batch to output
To be able to run batches directly to output with and option to refine and scale
Should also be possible for a single image
Defaults are off.
